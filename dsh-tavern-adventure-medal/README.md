# 酒馆冒险奖牌生成器 · dsh-tavern-adventure-medal

给 DSH Tavern 的一枚小玩具：从酒馆自己的角色卡与冒险存档里读出战绩，颁发一枚奶油色冒险奖牌。插画为底，信息小组件浮在上面；可以换皮肤、切换存档、保存成图片。

> 不需要导出存档，也不需要导入 `.jsonl` / `.dshsave`。插件直接读取酒馆自己的数据（只读）。

---

## 功能

- 输入栏奖牌小图标 → 冒险者公会选择器
- 第一步选角色卡（网格 + 封面缩略图），第二步选这段卡下的冒险存档
- 顶部「✨ 当前冒险」快捷项：一键读取当前会话的存档
- 奖牌弹窗：皮肤插画、加深的纵向渐变遮罩、竖排小标语、黄铜勋章、四个毛玻璃胶囊
- 四项战绩：冒险者（卡名）、冒险轮数、酒馆记忆（正文总字数）、开始冒险（存档创建日期）
- 勋章：径向渐变黄铜凸面（高光在左上）、外缘滚花齿边、浮雕五角星、蜜糖金 + 草莓粉两段折叠缎带；落下带约 5° 旋转，落定后阻尼摆动两下，再以 ±4° / 2.2s 轻摆
- 成就进度：底部双层大字——小字「当前成就 / 下一成就」，大字是贴纸风（栗子棕实心描边 + 多层偏移投影 + 约 -4° 倾斜，数字 1.3 倍并带蜜糖金描边）；文字过长自动缩小字号适配，出现时有一次回弹
- 多存档切换：奖牌顶部圆点/左右箭头；可返回选择器换卡
- 成就徽章：100 铜「小有名气」、300 银「传奇冒险者」、500 金「酒馆传说」、1000 虹彩「不朽传说」
- 皮肤：导入 jpg/png/webp，逐张 3:4 裁剪、压缩、存 localStorage；内置默认皮肤兜底
- 保存奖牌图片：1080×1440 PNG，构图与屏幕一致（毛玻璃与粒子为静态近似；进度大字用 canvas 的 strokeText + 多层 fillText 重画，与屏幕同款）
- 手机竖屏优先，触控目标 ≥44px

## 安装

### 方式一：插件面板（推荐）

1. 打开 DSH Tavern。
2. 设置 → DSH Tavern → 插件。
3. 点「上传 ZIP」，选择本仓库的 `dsh-tavern-adventure-medal.zip`。
4. 安装完成后刷新页面；如果宿主侧提示需要重启，按提示重启 DSH。

### 方式二：手动放入

把 `dsh-tavern-adventure-medal/` 整个文件夹放到：

```text
<DSH_HOME>/profile-data/tavern/data/plugins/dsh-tavern-adventure-medal/
```

宿主侧几秒内加载；浏览器侧刷新页面后出现。修改 `index.mjs` 后需要重启 DSH 才会生效。

## 使用

1. 进入一段游玩（story / script）。
2. 点输入栏尾部的奖牌小图标。
3. 选角色卡 → 选存档；或直接点「✨ 当前冒险」。
4. 奖牌出现后：
   - 顶部圆点/箭头：切换这张卡下的其他存档
   - 底部圆点：切换皮肤
   - 「保存奖牌图片」：导出 PNG
   - 「再来一枚」：回到存档列表
   - 左上「返回」：回到角色卡列表
5. 在冒险者公会选择器右上角点调色盘，可导入/裁剪/管理皮肤。

## 数据口径

- **冒险者**：角色卡名称（`data.name`，没有时用卡文件名去扩展名）。
- **冒险轮数**：**与酒馆列表同一个数**——优先用酒馆自己写进 `index.json` 的 `preview.turnCount`；老存档没有这个字段时，按酒馆的公式现算「最大轮次编号 − 开场白」。
  - 注意它**不等于**存档里 AI 回复的条数：回退 / 重说 / 重新生成会消耗轮次编号却不留下回复，所以编号会大于实际回复数（例：实际 300 条回复，编号可能已经到 420）。
  - 因为轮数决定徽章档位，本插件与酒馆显示同一个数，避免出现「酒馆一个数、奖牌另一个数」的情况。
- **酒馆记忆**：存档里所有消息正文的码点总数（AI 与玩家都算，emoji 按 1 个码点计），千分位显示并带「字」。
- **开始冒险**：这段存档的创建时间（`createdAt`），显示为 `2026.10.25`；读不到时显示 `--`。
- 角色卡五字段（`description + personality + scenario + first_mes + mes_example`）的码点总数仍由宿主侧返回（`persistentChars`），但奖牌上不再展示。
- **测试存档会被隐藏**：酒馆的会话列表会跳过 API 测试会话（`sessionId` 形如 `test-<uuid>` 且 `automation/<sessionId>.json` 的 owner 就是它自己），插件照抄这条规则，所以不会把测试残留的存档当成一段冒险列出来。

> 为什么还要读完整 chat？`getHistory` 只返回 DSH 会话里「最近已结算」的一段，老存档可能只读到最近几十轮；插件只读复用酒馆自己的 `chat-journal-store` 解码完整存档，才能算准字数。全程只读，不写入、不修改、不删除任何酒馆数据。

### 关于 `.jsonl` 与 `.dshsave`

- `.jsonl` 是 SillyTavern 兼容的聊天记录格式（第一行元数据、之后每行一条消息），通常用于导入/导出 SillyTavern 聊天。
- `.dshsave` 是 DSH Tavern 自己的存档包（ZIP 容器，内部是酒馆的 chat/session/card/worldbook 结构），用于在另一台酒馆继续玩。
- **本插件两个都不需要**：它直接读取当前酒馆里的角色卡和存档，不做导出/导入。只有你想把存档搬到别的机器时，才需要使用酒馆自己的「导出存档 / 导入存档」。

## 皮肤与存储

- 导入后必须裁剪：3:4 圆角取景框、框外压暗、拖动/双指/滚轮/滑块缩放。
- 输出宽 ≤1080、JPEG 质量 0.8；透明 PNG 会先铺奶油底，不会变黑。
- 皮肤存在 localStorage：
  - `dsh-tavern-adventure-medal:skins:v1`
  - `dsh-tavern-adventure-medal:selected:v1`
- 配额满时提示「皮肤太多啦，删掉几张旧的吧」，可在「管理皮肤」里删除；新裁的皮肤会留在内存里，删旧后可「重试保存」。

**同源限制**：`127.0.0.1`、`localhost`、局域网 IP、不同端口都是不同 origin，皮肤不互通。桌面和手机各自导入的皮肤不会自动同步；后续版本可改用酒馆的 `savePluginData` 做跨设备同步。

---

## 保存图片

- 输出 1080×1440 PNG，圆角外透明。
- 用逻辑坐标 420×560 绘制，和屏幕同一套布局。
- 毛玻璃用「预模糊皮肤 + 深色薄纱 + 白色半透明」近似；星星/彩纸为静态或省略。
- 因此是「静态构图高度一致」，不是逐像素复刻；`backdrop-filter` 的光学模糊无法在 canvas 里完全等价。

## 隐私

- 纯本地读取：角色卡、存档、头像都来自本机酒馆。
- 不联网、不上传、不调用模型、不消耗 API 额度。
- 消息正文只用于计数，绝不 `innerHTML`；卡名等用户数据只用 `textContent`。
- 皮肤只存在当前浏览器的 localStorage。

## 兼容性

- 目标：DSH Tavern 3.3.0 / DSH 0.2.1-rc.2 / 浏览器侧 `tavernUi.apiVersion = 10`。
- 入口逐级降级：`registerComposerTool`（v10）→ `registerHeaderTool`（v9）→ `registerComposerAction`（v2）。
- 如果酒馆后续版本改变了 chat 存储内部结构，插件会回退到官方 `getHistory`（可能只读到最近一段），并在奖牌上提示「部分正文暂时读不出来」。届时更新插件即可。
- 宿主侧通过只读方式读取 `<DSH_HOME>/profile-data/tavern/data/index.json` 和酒馆自己的 chat store；不会修改酒馆程序或数据。

## 常见问题

**看不到奖牌图标？**
- 确认当前是「游玩」模式（story / script），不是卡片工作台。
- 刷新页面；如果刚更新过 `index.mjs`，重启 DSH。
- 设置 → DSH Tavern → 插件里确认插件是「已启用 / 已加载」。

**奖牌轮数和存档列表不一致？**
- 现在两边是同一个口径（都取酒馆 `index.json` 的 `preview.turnCount`），正常情况下应该完全一致。
- 如果列表里某行显示 `≈`，说明那段存档没有 preview 字段、用的是现算值；奖牌会再读一次完整 chat 校正。
- 如果完整 chat 读不到，奖牌会提示部分正文暂时读不出来。

**为什么酒馆显示的轮数比 AI 回复条数多？**
- 轮数是「轮次编号」，回退 / 重说 / 重新生成会占用编号但不保留回复，所以编号会大于实际回复条数。
- 这是酒馆自己的计数方式，插件跟它保持一致。

**皮肤刷新后没了？**
- 检查是否换了地址（`localhost` / 局域网 IP / 端口变化）。
- 检查是否清了浏览器站点数据。
- 皮肤多时可能触发 localStorage 配额，删掉几张旧的再试。

**保存图片和屏幕不完全一样？**
- 这是静态 canvas 合成；毛玻璃、星星闪烁、彩纸粒子是近似/静态。构图、文字、颜色、布局与屏幕一致。

## 文件结构

```text
dsh-tavern-adventure-medal/
├─ package.json   # Tavern 插件清单
├─ index.mjs      # 宿主侧：只读查询 + chat store 解码
├─ client.js      # 浏览器侧：选择器 / 奖牌 / 皮肤 / canvas
├─ README.md
└─ LICENSE
```

`client.js` 是单文件、零依赖，内部按「存档解析 / 角色卡解析 / 统计 / 皮肤存储 / 裁剪器 / 奖牌 UI / Canvas 导出 / 覆盖层 / 插件入口」分区，方便后续修改。
