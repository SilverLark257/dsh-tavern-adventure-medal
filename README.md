# 🏅 酒馆冒险奖牌生成器

> 玩了四百轮，总得有点东西证明你不是在白玩。

给 DSH Tavern 的小插件。点一下输入栏那枚小奖牌，选卡、选存档，它就给你铸一枚
1080×1440 的冒险奖牌：黄铜勋章、双色缎带、毛玻璃胶囊，外加一行大字在你耳边循环：
「还差 63 轮！」

## ✨ 功能

- 🎖️ **选卡选档** — 角色卡网格带封面，存档带轮数与日期
- 🥇 **四项战绩** — 冒险者 / 冒险轮数 / 酒馆记忆（多少字）/ 开始冒险（哪天）
- 🏆 **成就徽章** — 100 铜 · 300 银 · 500 金 · 1000 虹彩，掉下来会晃两下才停
- 📈 **进度大字** — 贴纸风，粗到可以当路牌
- 🖼️ **换皮肤** — 导入图片、3:4 裁剪、存在本地
- 💾 **存图** — 1080×1440 PNG，构图与屏幕一致

## 📦 安装

**方式一（推荐）**

1. 打开 DSH Tavern
2. 设置 → DSH Tavern → 插件 → 上传 ZIP
3. 选 `dsh-tavern-adventure-medal.zip`，装完刷新页面

**方式二（手动）**

把 `dsh-tavern-adventure-medal/` 整个文件夹放进：

```text
<DSH_HOME>/profile-data/tavern/data/plugins/dsh-tavern-adventure-medal/
```

宿主侧几秒内加载；改过 `index.mjs` 要重启 DSH，改过 `client.js` 刷新页面即可。

## 🧮 千古悬案：为什么轮数比 AI 回复条数多？

因为「轮数」数的是**轮次编号**，不是回复条数。

回退一次、重说一次、重新生成一次，编号就往前走一格，旧回复却被换掉了。
于是编号越滚越大，实际留下的回复越来越少——像极了游戏时长和实际进度。

插件跟酒馆列表显示同一个数，省得你对着两个数字怀疑人生。

## 🖼️ 关于那张一两兆的图

PNG 是无损的，1080×1440 又铺了整张皮肤，压不动是正常的。
文件里只有像素：没有设备信息、没有文件路径、没有时间戳，也没有聊天记录。
嫌大可以自己转 JPG，体积大概能小八倍。

## 🔒 隐私

- 只读本机数据：不联网、不上传、不调模型、不花额度
- 消息正文只用于计数，不渲染、不外传
- 皮肤只存在你自己的浏览器 localStorage
